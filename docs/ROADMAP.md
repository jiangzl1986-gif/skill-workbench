# 发展路线

第一步是让 Skill 创作过程看得见、改得清楚：完整导入、知识地图、共享模块库、整个 Skill 的创作起点、内部组装、草稿和开发交接。

接下来的方向：

| 方向 | 希望解决的问题 | 当前状态 |
| --- | --- | --- |
| 安装与使用体验 | 减少首次依赖准备，完善桌面入口、新电脑和其他系统验证 | Windows 测试版；其他系统未实测 |
| 接口与规则设计 | 更清楚地显示输入输出、前置、条件、冲突和未选依赖 | 结构候选和设计意图已保留；自动语义解释未实现 |
| 知识 / 经验 / 证据库 | 统一归纳历史验证、方法经验和资料，并回指 Skill 与模块 | 计划，未实现；原材料保留 |
| 发布、同步和调用链 | 用明确凭证串起正式版、安装、工作台登记、项目冻结和对话框调用 | 只读状态与人工交接；实际调用回执未实现 |
| 通用互操作 | 更多来源格式、设计包迁移和跨环境恢复 | 首版以 SKILL.md 文件夹和 ZIP 为主 |

欢迎提交创作场景和最小公开样例。路线图不代表已支持，不承诺未经验证的自动执行能力。
