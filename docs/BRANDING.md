## English

Compose AI Skills on an infinite canvas.

**SkillTangram** (Chinese name: **技能七巧板**) was previously called **Skill Workbench**. The repository and Pages paths, release tags, existing download assets and checksums, installation/data directories, draft storage keys and export formats remain unchanged.

Existing installers and historical screenshots may still show Skill Workbench. They are earlier builds of this same project. This naming update does not silently replace a published binary or update an installed copy. Current source and the browser example use the new name; future builds retain compatible paths and shortcut locations.

Understand existing Skills, remix modules from different sources on an infinite canvas, and hand the complete design to your agent for validation and implementation.
