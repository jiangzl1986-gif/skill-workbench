# Skill Workbench 0.1.0-beta.1 · 首个公开测试版

**用无限画布，创作、整理与重组 AI Skill。**

把已有 Skill 导入自己的本机工作空间，在知识地图中看清规则与来源，在共享模块库里跨 Skill 选择内容，再进入大模块内部加入、替换或移除小模块。把新的想法画成可以检查、可以继续修改的设计，交给自己的开发者或 AI 开发助手完成接入。

## 本版功能

- 知识地图：模块、文件、规则、引用、原文行号与中文搜索。
- 创作画布：整套结构载入、空白方案、拖拽布局、大小模块内部组装、连线与剪线。
- 共享模块库：跨来源搜索、分层筛选、来源版本和原文范围保留。
- 导入与同步：本机目录、目录上传或 ZIP、指定目录扫描；预览后接入，明确采用新版本并保留旧快照。
- 保存、重新打开与导出：包含完整来源原文、校验、父子位置、内部连接和接入要求。
- 维护交接与状态查看：生成准确版本的只读分析指令；未提供正式/安装/使用凭证时保持未知。

## 下载与使用

下载下面的 **skill-workbench-0.1.0-beta.1-windows.zip**，解压后双击 `setup.cmd`，准备完成后双击 `start.cmd`。首次需 Python 3.11、Node.js 22 和联网下载依赖；不需要模型 API Key。随后到“导入与同步”选择自己的 Skill，或用 `examples` 内的两份演示 Skill 开始体验。

下载包含程序源码、预先构建的页面、中文指南、英文介绍、公开示例及依赖许可；不含 Python/Node 安装器。`SHA256SUMS.txt` 用于核对下载。GitHub 自动生成的 Source code 包是源码，也可按相同步骤准备。

## 测试与边界

32 个回归测试项通过；同一台 Windows 电脑的独立目录安装/构建/启动/重启保留数据通过；实际浏览器完成跨来源内部组装并下载，另一个独立进程核对原文件字节和包哈希。

这是公开测试版。第二台全新电脑、其他系统、任意 Skill 的业务执行和独立语义审查仍需后续验证。画布和导出提供设计，不会自动生成或执行新 Skill。知识库和自动分发/实际调用回执列入后续路线图。

程序采用 MIT；导入内容继续遵循其原许可。资料留在本机，源文件只读；公开包不携带私人 Skill 或运行数据。

欢迎在 Issues 分享可公开的最小示例和真实创作需求。
