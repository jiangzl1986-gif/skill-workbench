# 公开演示资料

这两个示例由本项目独立编写，随程序采用 MIT。它们专门用于演示来源阅读和设计，不能证明任意 Skill 的业务语义或实际生成已经通过。

1. 在工作台“导入与同步”中，选择 `notes-to-outline` 文件夹，预览并确认。
2. 再导入 `evidence-review` 文件夹。
3. 到组装台载入笔记转大纲的整套范围。进入“大纲设计”内部，从共享模块库加入“证据检查”模块，连接您希望的交接。
4. 写明输入、输出和修改意图，保存并导出。查看设计包中的完整原文和父子位置。

结构模块自动提取，执行连线应按原文确认。本例的整套载入不会自动生成连线，也不会自动运行这些 Skill。
